# Sales Prediction using Python

## CodeAlpha Data Science Internship Project

This project predicts product sales using Machine Learning techniques based on advertising data.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Project Overview

The project uses Linear Regression to predict sales based on:

- TV Advertising
- Radio Advertising
- Newspaper Advertising

## Features

- Data Cleaning
- Data Visualization
- Model Training
- Sales Prediction
- Performance Evaluation

## Machine Learning Model

- Linear Regression

## Output

The model predicts future sales using advertising expenditure data.
